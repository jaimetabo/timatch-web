2. Was Timatch speichert und wo

Timatch ist eine Offline-First-App. Alle Inhalte, die du anlegst — Spielesammlung, Personen, Orte, Sessions, Zugzeiten, Punkte, Fotos, Tags und Einstellungen — werden lokal auf deinem Gerät über Apples SwiftData-Framework gespeichert.

Wenn du in den Einstellungen die iCloud-Synchronisierung aktivierst, werden dieselben Daten zusätzlich in der privaten Datenbank deines iCloud-Accounts über Apple CloudKit abgelegt, damit sie auf deinen anderen Geräten verfügbar sind. Für diese Verarbeitung gilt die Datenschutzerklärung von Apple. Der Entwickler von Timatch hat darauf keinen Zugriff und erhält keine Kopie.

Ohne Timatch-Konto spricht die App mit keinem Server des Entwicklers. Für das freiwillige Konto und die Web-Version gibt es den Dienst unter api.timatch.de (Abschnitt 7).

3. Welche Daten der Entwickler erhält

Ohne Konto: keine. Mit Konto: die in Abschnitt 7 genannten Daten, und nur zu dem dort genannten Zweck. Timatch enthält kein Analyse-SDK, keinen Crash-Reporting-Dienst, kein Werbe-SDK und kein Tracking Dritter. Es werden keine Nutzer-Kennungen, Gerätekennungen oder Nutzungsstatistiken an den Entwickler übertragen.

4. Verbindungen, die die App aufbaut

BoardGameGeek

Wenn du aktiv nach einem Spiel suchst oder eine Sammlung importierst, sendet die App deinen Suchbegriff bzw. deinen BoardGameGeek-Benutzernamen an die öffentliche BoardGameGeek XML API2 (boardgamegeek.com), um Spiel-Metadaten abzurufen. Das geschieht ausschließlich, wenn du es auslöst. Weitere Daten werden nicht übertragen. BoardGameGeek ist ein unabhängiger Dritter; für die dortige Verarbeitung gilt deren eigene Datenschutzerklärung. Timatch steht in keiner Verbindung zu BoardGameGeek.

Titelbilder von BoardGameGeek

Spiele-Titelbilder, die aus BoardGameGeek stammen, werden beim Anzeigen direkt vom Bildserver von BoardGameGeek geladen (cf.geekdo-images.com). Dabei erfährt dieser Server — wie bei jedem Bildabruf im Internet — deine IP-Adresse und welches Bild angefordert wurde. Ein selbst aufgenommenes Foto ersetzt das Titelbild und wird ausschließlich auf deinem Gerät gespeichert.

Lokales Netzwerk (Apple TV, Apple Watch, Zweitgerät)

Um die Session auf einem Apple TV, einer Apple Watch oder einem zweiten iPhone/iPad anzuzeigen, verbindet sich Timatch über dein lokales WLAN direkt mit diesem Gerät (Apple MultipeerConnectivity und Bonjour). Die Session-Daten laufen von Gerät zu Gerät. Sie gehen weder über das Internet noch an den Entwickler.

In-App-Käufe

Käufe von Timatch Pro werden vollständig von Apple über StoreKit abgewickelt. Der Entwickler erhält nur die anonymisierten Verkaufs- und Finanzberichte von Apple und sieht weder deine Zahlungsdaten noch deinen Apple Account.

6. Apple Intelligence

Auf Geräten mit Apple Intelligence kann Timatch deine Statistiken als kurze Zusammenfassung formulieren — über Apples geräteinternes FoundationModels-Framework. Das läuft vollständig auf deinem Gerät. Weder Eingaben noch Statistiken verlassen das Gerät. Auf allen anderen Geräten wird stattdessen eine regelbasierte Auswertung verwendet.

7. Timatch Web (Web-Version, app.timatch.de)

Die Web-Version läuft im Browser und speichert alles zunächst nur dort (Browser-Speicher des Geräts). Ohne Konto verlässt nichts das Gerät — mit zwei Ausnahmen, die du selbst auslöst: die Suche bei BoardGameGeek und die Funktionen, die unten einzeln stehen.

Server und Hosting

Die Web-Version wird von Cloudflare, Inc. (101 Townsend St, San Francisco, CA 94107, USA) ausgeliefert (Cloudflare Pages) und nutzt einen kleinen Dienst auf Cloudflare Workers unter api.timatch.de. Cloudflare verarbeitet dabei technisch notwendig deine IP-Adresse und Anfragedaten; Cloudflare ist nach dem EU-US Data Privacy Framework zertifiziert, zusätzlich gelten EU-Standardvertragsklauseln. Der Dienst zählt Anfragen je IP-Adresse für eine Minute, um Missbrauch zu begrenzen; darüber hinaus werden keine Zugriffsprotokolle mit Personenbezug aufbewahrt.

Timatch-Konto (freiwillig)

Das Timatch-Konto gibt es in der Web-Version; die iPhone-App nutzt dasselbe Konto, sobald die Funktion dort freigeschaltet ist. Wer ein Konto anlegt, gibt seine E-Mail-Adresse an und erhält eine Anmelde-Mail mit Link und 8-stelligem Code (kein Passwort). Mit Konto liegen deine Partien, Personen, Spiele, Wertungsblöcke, Einstellungen und Fotos auf unserem Server bei Cloudflare (Datenbank D1 und Speicher KV), damit sie auf jedem Gerät erscheinen, auf dem du dich anmeldest. Rechtsgrundlage ist die Erfüllung des Nutzungsvertrags (Art. 6 Abs. 1 lit. b DSGVO). Link und Code sind 15 Minuten gültig und nur einmal verwendbar; nach fünf falschen Code-Eingaben verfällt der Code. Geräte-Sitzungen gelten 90 Tage. Beim Abmelden werden deine Daten vom jeweiligen Gerät entfernt; im Konto bleiben sie. Du kannst dich jederzeit auf einzelnen Geräten abmelden, deine Daten als Datei herunterladen und das Konto in den Einstellungen mit allen Daten löschen; danach ist alles auf dem Server gelöscht, auf deinem Gerät bleibt es.

Die Anmelde-Mail verschickt Brevo (Sendinblue GmbH, Köpenicker Straße 126, 10179 Berlin) in unserem Auftrag; Brevo erhält dafür deine E-Mail-Adresse.

Cloud-Sicherung mit Code (ohne Konto)

Alternativ zum Konto kannst du eine Sicherung mit einem Code anlegen. Sie wird vor dem Hochladen auf deinem Gerät verschlüsselt (AES-GCM); der Server speichert nur die verschlüsselten Bytes unter einer aus dem Code abgeleiteten Kennung und kann sie nicht lesen. Ohne Code sind die Daten nicht wiederherstellbar. Die Sicherung wird nach 180 Tagen ohne Aktualisierung automatisch gelöscht.

Tisch-Display und Zuschauer

Startest du ein Tisch-Display, überträgt dein Gerät den Spielstand (Namen der Personen, Farben, Zeiten, Punkte) an unseren Server, der ihn an alle weitergibt, die den sechsstelligen Code kennen. Der Stand liegt dort höchstens 24 Stunden nach der letzten Änderung und wird dann gelöscht. Teile den Code nur mit Leuten am Tisch.

BoardGameGeek über unseren Server

Spielsuche und Sammlungsimport der Web-Version laufen über api.timatch.de an BoardGameGeek (siehe Abschnitt 4); an BGG geht nur der Suchbegriff bzw. der BGG-Nutzername, keine Kontodaten. Antworten werden auf unserem Server zwischengespeichert (Suche 24 Stunden, Spielinfos 7 Tage, Sammlungen 1 Stunde).

KI mit eigenem Schlüssel

Die KI-Funktionen der Web-Version arbeiten nur, wenn du einen eigenen API-Schlüssel von Anthropic (Claude) oder OpenAI (ChatGPT) einträgst. Der Schlüssel bleibt in deinem Browser; Anfragen (Statistik-Auszüge, Spielstände, deine Sammlung, Namen der Personen) gehen dann direkt von deinem Gerät an den gewählten Anbieter nach dessen Datenschutzbestimmungen. Wir sehen diese Anfragen nicht.

Fotos

Tischfotos und Personenfotos liegen im Browser-Speicher des Geräts; mit Konto zusätzlich in deinem Konto auf unserem Server (siehe oben). Sie werden nirgends sonst hochgeladen.

Nach der DSGVO steht dir außerdem ein Beschwerderecht bei einer Aufsichtsbehörde zu. Bei Fragen zu dieser Erklärung: hello@timatch.de.
